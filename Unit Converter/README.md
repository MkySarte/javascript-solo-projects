# Metric/Imperial Unit Converter

A simple unit converter built with HTML, CSS, and JavaScript as part of my JavaScript learning journey with Scrimba.

## About the Project

This project is a browser-based unit converter.

The goal was to practise fundamental JavaScript concepts by building an interactive application that converts a single value between common metric and imperial units.

## Features

- Enter a value for conversion
- Convert meters to feet and feet to meters
- Convert liters to gallons and gallons to liters
- Convert kilograms to pounds and pounds to kilograms
- Display all conversion results at the same time
- Format conversion results for easier reading

## JavaScript Concepts Practised

- Variables
- Constants
- Functions
- Function parameters
- Arithmetic operators
- Reading values from input elements
- Number formatting with `toFixed()`
- DOM manipulation
- Event handling
- Template literals

## What I Learned

While building this project, I practised how to take a value entered by the user, process it with JavaScript, and display the calculated results in the browser.

One important part was understanding that the same conversion factor can be used in both directions:

- Multiplication converts from the metric unit to the imperial unit
- Division converts from the imperial unit back to the metric unit

I also improved my understanding of:

- Reading values from an input element
- Reacting to a button click
- Separating each type of conversion into its own function
- Passing values into functions with parameters
- Updating multiple DOM elements
- Formatting decimal results

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.
