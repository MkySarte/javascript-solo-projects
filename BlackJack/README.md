# Blackjack Game

A simple Blackjack game built with HTML, CSS, and JavaScript as part of my JavaScript learning journey with Scrimba.

## About the Project

This project is a browser-based Blackjack game.

The goal was to practise fundamental JavaScript concepts by building a small interactive application instead of only working through isolated exercises.

## Features

- Start a new Blackjack game
- Draw two random cards
- Draw additional cards
- Calculate the current card sum
- Display different game states
- Detect Blackjack
- Detect when the player has gone over 21

- Variables

- Functions
- Objects

- `if` / `else` statements
- Comparison operators
- Logical operators
- `for` loops
- The JavaScript `Math` object

## What I Learned

While building this project, I practised how different JavaScript concepts work together inside a complete application.

One important part was generating random card values with:

- `Math.random()`
- `Math.floor()`
- A defined minimum and maximum range

I also improved my understanding of:

- Updating application state
- Storing cards inside an array
- Recalculating the card sum
- Rendering updated values in the browser
- Separating logic into functions

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No additional installation is required.
