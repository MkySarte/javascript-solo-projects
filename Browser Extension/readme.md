# Chrome Leads Tracker

A simple Chrome extension built with vanilla JavaScript to save, manage, and revisit useful URLs directly from the browser.

This project was completed as part of the **Scrimba JavaScript Course**, with the implementation written by me for learning and portfolio purposes.

## Features

- Save links manually
- Save the currently active browser tab
- Display saved links dynamically
- Open saved links in a new tab
- Persist data using `localStorage`
- Delete all saved links with a double-click
- Responsive and lightweight interface

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Chrome Extensions API
- Local Storage

## Installation

1. Clone this repository.
2. Open Chrome and navigate to:

```
chrome://extensions
```

3. Enable **Developer Mode**.
4. Click **Load unpacked**.
5. Select the project folder.
